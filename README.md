# Flood Forecast Viewer

Interactive proof-of-concept viewer for Bay of Plenty cumulative forecast rainfall data.

## Prototype status

This viewer is an early proof of concept. The display and click-value mechanics have been checked against the source raster grid, but the forecast model, rainfall units, and time-step interpretation require operational confirmation before the viewer is used for flood-response decisions or public advice.

## Current prototype

- 85 cumulative rainfall forecast frames
- NZST valid times
- Animated timeline and playback controls
- Click-to-read rainfall values
- Surface drainage catchments and place labels
- Imagery and streets basemaps
- Rainfall opacity control
